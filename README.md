# snippets

Мелкие скрипты и одноразовые задачи, не тянущие на отдельный репозиторий, сгруппированы по направлениям.

- `data-parsing/budget-places-parser/` — три итерации одной задачи: парсинг PDF/xlsx с бюджетными местами вузов по годам в csv (`v1-places` → `v2-points` → `v3-read-tables`, от старой к новой)
- `nlp-text-morphology/` — работа со стеммингом/морфологией текста
- `visualization/job_satisfaction_radar_chart.py` — построение radar-диаграммы (удовлетворённость работой)
- `misc/moneyjob/` — разные задачи с подработки: телеграм-бот, игра, task1/task2
- `misc/song-matcher-spotify/` — сопоставление списка треков с Spotify/Genius и добавление в плейлист
- `misc/sanych-doc-report/` — генерация отчёта в docx/xlsx по конкретной задаче
- `misc/subd-coursework/` — лабораторная по БД (+ файл `СУБД_ЛАБ1.docx`)
- `scraping/legal-acts-scraper/` — скрапер нормативных актов + сопутствующие учебные файлы
