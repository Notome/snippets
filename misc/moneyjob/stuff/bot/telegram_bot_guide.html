AI-Прототипирование
Telegram-бота

aiogram 3.x · Python · пошаговый гайд

01
Получите токен в BotFather
🤖

Откройте Telegram и найдите бота @BotFather. Отправьте команду /newbot, введите имя и username бота (должен заканчиваться на bot). Скопируйте полученный API Token.

02
Узнайте свой Telegram ID
🆔

Напишите боту @userinfobot любое сообщение — он ответит вашим числовым ID. Скопируйте его (например: 123456789).

03
Настройте файл feedback_bot.py
⚙️

Откройте скачанный файл и замените 4 значения в самом верху:

BOT_TOKEN ="токен от BotFather"
ADMIN_ID =ваш числовой ID
AUTHOR_NAME ="Ваше Имя Фамилия"
AUTHOR_LINK ="https://t.me/username"
04
Установите библиотеку и запустите
🚀

Откройте терминал (или консоль Replit) в папке с файлом и выполните:

# Установка библиотеки (один раз)
pip install aiogram

# Запуск бота
python feedback_bot.py

Если всё верно, в консоли появится сообщение о старте polling. Бот готов к работе!

05
Отладка ошибок
🐛

Если бот упал с ошибкой — скопируйте текст из консоли и отправьте в ChatGPT / Claude с запросом:

"Исправь ошибку в коде aiogram 3.x:
[вставьте текст ошибки]"
⚠️ Самые частые ошибки: неверный токен (проверьте кавычки), неверный ADMIN_ID (должно быть число без кавычек), или не установлена библиотека aiogram.
